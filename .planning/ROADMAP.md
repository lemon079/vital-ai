# Roadmap: VitalSense AI

## Overview

A phased journey from a brownfield Next.js codebase with legacy database redundancies into a secure, state-managed clinical analyzer. We will start by establishing secure agentic reasoning logic and fact-checking guardrails within the LangGraph backend. Next, we will expand conversational nodes to handle progressive follow-ups and custom summaries. Finally, we will refactor client-side state management, polish the dashboard with rich micro-animations, and implement an automated verification suite.

## Phase Details

### Phase 1: Agentic Diagnosis Guardrails & Logic
- **Goal**: Implement secure clinical reasoning logic to synthesize conversations/abnormal lab values, cite factual evidence, and enforce medical disclaimers.
- **Depends on**: Nothing
- **Requirements**: FLOW-03, FLOW-04, FLOW-05, FLOW-06
- **Success Criteria**:
  1. LangGraph outputs a personalized medical summary explaining "why it is happening" using active chat data.
  2. The agent strictly cites concrete, factual lab results from the active session.
  3. Every clinical conclusion generated by the agent is appended with a prominent medical disclaimer.
- **Plans**: 2 plans

Plans:
- [x] 01-01: Build clinical conclusion synthesizer and citation rules inside `lib/agent/nodes/clinical-summary.ts`. (completed 2026-06-02)
- [x] 01-02: Implement evidence verification checks and automated disclaimers in `lib/agent/nodes/guardrails.ts`. (completed 2026-06-02)
